Nexora

Minecraft server list with live player counts and an in-game mod

Nexora is a Minecraft server list built around honest data: live player counts from my own scanner, no server botting, no cracked servers, and smart filters so you can actually find your next grind session. A Fabric mod lets players browse and join servers without leaving Minecraft.

This started as a question with a friend: "why don't we just have a server browser in Minecraft? Just like in Roblox." My first reaction was that I didn't even know if it was possible.

So I asked my friend Claude to check it out, and in 20 minutes it had built a mod. That was the moment I thought: oh, this is interesting — and it actually looks pretty good.

I went looking for other mods that did the same and found one, but it was just a normal, super long list of thousands of servers, cracked and not cracked. That's when I started cooking up ideas. I prompted most of it together in a few hours and fine-tuned it over the following days.

The website is the first thing people see, so I wanted a clear UI with a little Minecraft feel — that's why the first thing you see is a Minecraft-inspired world.

Goal

Make finding a Minecraft server as easy as a server browser in Roblox — without botted player counts, without cracked servers and without a never-ending list. Players get a clean list they can trust, and servers that play fair get found.

Features

  • Live player counts from my own scanner (hundreds of servers, ~90k players tracked)
  • No server botting and no cracked servers — cracked servers fall off immediately
  • Servers under 20 players are never shown, to protect players and private servers
  • Search by name, address or MOTD with smart filters
  • Server analytics and history
  • Fabric mod (1.21.11 – 26.3) to browse and join servers in-game
  • Microsoft login (Minecraft account linking is in progress)

How it's built

A slow, rate-limited scanner collects player counts, MOTDs and versions. That data feeds the website (discover, servers and analytics pages) and the in-game Fabric mod, which shows the same list inside Minecraft. Login goes through Microsoft auth.

Roadmap

  • Link Microsoft login to Minecraft, so a logged-in user shows their Minecraft name instead of their real name
  • Anonymously link each mod client to an account — and find a way to verify the client isn't cracked
  • Show users exactly which data we have on them, with one-click delete (and an in-game opt-in for saving data at all)
  • More filters and server categories

Dev log

Microsoft login, and a privacy-first plan

2026-11-19 · update

I got a Microsoft auth key, so you can now log in with Microsoft. The next step is Minecraft: when you log in, we can show your Minecraft credentials instead of your real name, and use an anonymous link to know which client with the mod is connected to which account.

The open question is how to verify the Minecraft client isn't cracked.

The only thing this will do is show you what data we have on you, so you can delete it with one click. The mod will also ask in-game whether you want your data saved at all — otherwise there is nothing except the requests to the server for the server list.

I also want to protect players and private servers, so servers under 20 players will never be shown, and cracked servers fall off immediately.

Why I scan instead of botting

2026-11-05 · problem

To get live player counts I could have used a Minecraft bot to join and check on servers. I felt like that was wrong to do, so I researched a little and found I could scan servers instead.

The risk: my home internet provider might not like it and shut down the wifi. Sorry mom, I took that risk. I set the scanner to run very slowly so it wouldn't happen fast, and hoped for the best.

It's still a much better approach than actual botting.
