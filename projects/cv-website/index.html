Personal CV & About Me Platform

This website: a CV that doubles as a portfolio and a dev log

The site you're looking at. It started as a CV and grew into a personal hub: a scrolling one-page overview of who I am, with its own pages for every work experience and every project, including a dev log where I post updates and the problems I ran into.

A normal CV is a PDF that says what you did. I wanted something that shows it: who I am, the work I've done, what I'm studying, and the projects I'm building, including the ones that failed or are still stuck.

The home page is one scrolling story with a section per theme: About Me, Work Experience, Academics, Projects and Contact. Each experience and each project then opens its own page with the longer, honest version — what I did, what I learned, what I could have done better, and for projects a dev log with the problems I ran into.

Everything on the site is data-driven. To add a project, an experience or a dev-log post I edit a single data file and the pages, carousel and timelines update by themselves.

Goal

A CV that shows the real picture, including failures and lessons, and that grows with me: every project gets a page and a dev log where I post updates and problems.

Features

  • One-page scrolling overview with snap sections and a section navigator
  • Timeline sections for Work Experience, Academics and About Me, with future ambitions marked
  • Detail page for every work experience: what I did, my focus, what I learned and what I could do better, with photos or a company website preview
  • Projects carousel with swipe, image galleries and links to every project
  • Project pages with the story, goal, features, roadmap, an architecture graph and a dev log you can filter by update, problem, solution and milestone
  • Interactive architecture diagram for projects whose source code stays private
  • Downloadable PDF CV and contact links
  • Responsive layout and animations with Framer Motion
  • Content lives in data files, so adding things doesn't need new components

How it's built

A React and TypeScript single-page app built with Vite and styled with Tailwind CSS. Routes are handled with a hash router so it can be hosted as static files on GitHub Pages. Experiences, academics and projects (including their dev-log posts) come from typed data files that the pages render.

Roadmap

  • Keep posting dev-log updates for every project
  • Add real screenshots and images for the projects that still use placeholders
  • Add more projects and experiences as they happen
